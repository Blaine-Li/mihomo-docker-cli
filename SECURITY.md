# Security Policy

## Supported version

Security fixes are provided for the latest version on the `main` branch.

## Reporting a vulnerability

Please report vulnerabilities through GitHub Private Vulnerability Reporting:

https://github.com/Blaine-Li/mihomo-docker-cli/security/advisories/new

Do not open a public issue for an unpatched vulnerability. Do not include real subscription URLs, Mihomo configurations, proxy credentials, API secrets, or other personal data in public issues, pull requests, or logs.

Include a concise description, affected version, reproduction steps using redacted or synthetic data, and the expected impact. You should receive an initial response within seven days.

## Secrets already exposed

Removing a secret from the latest commit does not remove it from Git history, forks, caches, or existing clones. Revoke or rotate exposed credentials first, then rewrite history if necessary.
